## 推荐岗位定位

岗位方向：杭州线下全职小白互动娱乐主播。

核心人群：

- 刚来杭州、需要落脚点的人。
- 没有直播经验，但愿意学表达、互动、节目效果的人。
- 做过带货或娱乐直播，但被维护、暧昧经济、低流量困住的人。
- 不确定自己能不能做直播，但愿意先了解的人。

不主打人群：

- 只问高薪、不愿意按排班直播的人。
- 只想线上兼职的人。
- 只想靠颜值聊天或私下维护变现的人。
- 不能接受平台线上协议、排班和运营复盘的人。

## BOSS 发布字段建议

### 岗位标题

主推标题：

```text
0基础抖音主播｜保底6K起｜包住
```

标题设计原因：

- `0基础`：降低小白点击门槛。
- `抖音主播`：明确岗位类型和平台。
- `保底6K起`：第一屏给稳定感，但详情必须解释保底不是无条件底薪。
- `包住`：匹配刚来杭州、租房压力、线下岗位本地转化。

备用标题：

```text
小白互动主播｜保底6K｜一对一带教
素人主播孵化｜杭州线下｜首月包住
抖音娱乐主播｜不带货｜运营带教
```

标题测试建议：

- 第 1 轮只测主推标题 3-5 天，看详情打开、聊天打开、微信采集。
- 备用标题每次只换一个主要变量，不要同时改薪资、岗位详情和城市。

### 岗位类别

建议优先选择：

```text
主播 / 网络主播 / 视频主播
```

不要把岗位放到泛娱乐、销售、客服等不准确类别里，否则推荐人群会变散。

### 薪资字段

建议：

```text
6-10K
```

详情页必须补充：

- 全职保底通常从 6K 起。
- 保底按有效直播时长和运营规则计算，不是无条件底薪。
- 不拿保底时分成更高；正式开播前可选择，开播后不建议频繁更改。

### 工作地点

建议：

```text
杭州线下直播间
```

岗位不要同时写“居家可做”和“线下包住”。如需线上招聘，另开线上岗位。

### 经验与学历

建议：

```text
经验不限 / 学历不限
```

要求写法：

- 不要求直播经验。
- 不要求才艺基础。
- 需要能按排班直播，愿意学习直播互动和复盘。
- 需符合抖音直播平台实名认证和开播要求。

### 关键词

建议关键词：

```text
抖音主播、娱乐主播、互动主播、零基础、小白、素人孵化、免费培训、一对一带教、保底、包住、运营带教、涨粉、直播间、杭州
```

不建议关键词：

```text
颜值主播、高薪无责、轻松月入10万、无门槛暴富、日结保底、无需学习
```

## 岗位详情页文案

### 第一屏开头

```text
我们招杭州线下抖音互动娱乐主播，0经验可以教，首月可免费住宿，保底6K起。先说清楚：保底不是无条件底薪，是你按运营排班直播后，收入没达到保底时公司按规则补差。
```

这一句要解决三件事：

- 让候选人一眼知道做什么。
- 把 `0经验`、`包住`、`保底6K` 放在前面。
- 立刻区分保底和底薪，降低后续误解。

### 我们做什么直播

```text
我们做的是抖音互动娱乐直播，不是传统带货，也不靠私下暧昧维护。核心是直播间的互动感、节目效果、表达能力和稳定开播。

你不用一上来就会直播，前期会有人带你熟悉账号、人设、直播间节奏、互动话术、复盘方式。
```

### 你能获得什么

```text
1. 全职保底：通常 6K 起，根据有效直播时长和排班规则计算。
2. 分成：拿保底分成 40%，不拿保底分成 45%，正式开播前确认。
3. 住宿：线下主播首月可免费住宿，适合刚来杭州还没稳定住处的人。
4. 带教：运营一对一带教，从直播内容、互动方式、复盘、起号节奏开始教。
5. 成长：适合想做抖音、想练表达、想做个人账号和直播间互动的人。
6. 奖励：新人赛、内部比赛、转介绍等奖励按公司当期规则执行。
```

### 工作内容

```text
1. 在公司线下直播间按排班开播。
2. 配合运营做直播内容、互动节奏和复盘调整。
3. 学习直播间表达、互动、控场、粉丝关系维护。
4. 根据账号情况参与短视频或直播素材优化。
5. 遵守平台规则，不做违规内容。
```

### 任职要求

```text
1. 经验不限，小白可以从 0 学。
2. 愿意开口表达，愿意练习，不怕前期不熟练。
3. 能按排班稳定直播，愿意接受运营复盘。
4. 对抖音、直播、互动内容有兴趣。
5. 符合抖音直播平台实名认证和开播要求。
```

### 我们不希望你误解

```text
1. 保底不是无条件底薪，需要按排班直播并符合规则。
2. 我们不收培训费、报名费、签约费。
3. 签的是抖音平台线上合作/入会相关协议，不签线下绑定合同；具体退出规则面聊时会讲清楚。
4. 主播收入和直播时长、内容表现、学习配合度、平台流量有关，不承诺无条件高薪。
```

### 适合你，如果你是

```text
1. 刚来杭州，想先有住处和一份能学习成长的工作。
2. 没做过直播，但愿意试试表达、互动、上镜。
3. 做过带货或娱乐直播，想换一个不靠暧昧维护的方向。
4. 想做抖音，但不知道从哪里开始。
```

### 不太适合你，如果你是

```text
1. 只想挂名拿保底，不想按排班直播。
2. 不愿意学习直播话术和复盘。
3. 只想线上兼职，本岗位是杭州线下全职方向。
4. 期待不努力就稳定高收入。
```

## BOSS 第一条招呼语

### 通用小白版

```text
你好，我这边招杭州线下抖音互动主播，0经验可以教，保底6K起，首月可提供住宿。看你经历还挺适合先了解一下直播方向，要不要我发你看看我们具体做什么内容？
```

设计点：

- 岗位、城市、待遇、0经验、住宿一次讲清。
- 结尾用“发你看看内容”引导下一步，不直接堆资料。

### 杭漂/外地来杭州版

```text
你好，我们这边是杭州线下抖音互动主播，首月可安排住宿，0经验有人带。刚来杭州找房和找工作都挺麻烦的，你要不要先看看我们直播间具体做什么？
```

### 有直播经验版

```text
你好，看你有直播相关经历。我们这边做抖音互动娱乐直播，不是传统带货，也不靠私下暧昧维护，运营会带起号和复盘。你要不要看看我们现在的直播内容和扶持方式？
```

### 看过岗位未投递版

```text
刚看到你看过我们岗位。我这边简单说一下：杭州线下、0经验可带、保底6K起、首月可住。你如果主要想了解收入、住宿还是直播内容，我可以先讲你最关心的。
```

## 聊天承接结构

### 候选人问“你们做什么内容”

```text
我们是抖音互动娱乐直播，不是传统带货，也不做私下暧昧维护。
我可以发你看看直播内容，不过 BOSS 这边不太方便发视频，微信上看会更直观。你方便加一下吗？
```

### 候选人没问内容但有兴趣

```text
这个岗位光用文字说会比较抽象，我发你看看我们直播间具体做什么内容，你会更好判断自己适不适合。
```

### 候选人问“保底是不是底薪”

```text
不是底薪，这点我先讲清楚。保底是你按运营排班直播后，如果当月收入没达到约定保底，公司按规则补差；不是不播也有的固定工资。
```

### 候选人问“我没经验能不能做”

```text
可以，我们这个岗位就是按小白孵化设计的。我们更看重你愿不愿意学、能不能稳定开播和复盘。直播能力不是一上来就有，是练出来的。
```

### 候选人问“我长相普通能不能做”

```text
能不能做不只看长相。我们做的是互动娱乐直播，很多时候有特点、愿意表达、愿意练，比单纯好看更重要。具体适不适合，可以先看你的表达状态和学习意愿。
```

### 候选人问“签约会不会被绑定”

```text
我们不收签约费、培训费，也不签线下绑定合同。走的是抖音平台线上合作/入会相关协议，具体周期、退出规则和注意事项会在面聊前讲清楚，你确认能接受再继续。
```

### 候选人问“能不能先电话”

```text
可以，电话会比文字讲得清楚。你现在方便 5 分钟吗？我先把直播内容、保底规则、住宿和签约边界给你讲明白。
```

### 候选人拒绝电话

```text
没事，那我们先文字沟通。你现在最关心的是收入、住宿、直播内容，还是签约退出规则？
```

## 候选人筛选问题

不要一次全问，按聊天进度拆开：

1. 你现在是在杭州，还是准备来杭州？
2. 之前有做过直播、短视频、销售、客服或线下互动类工作吗？
3. 你更关心稳定保底、住宿落脚，还是后续成长空间？
4. 如果合适，能不能接受线下直播间按排班开播？
5. 你对抖音直播最大的顾虑是什么？

破冰时避免直接问：

- 有没有男朋友/女朋友。
- 家里情况。
- 现在收入。
- 过多隐私经历。

## 图片与素材策略

BOSS 岗位建议上传：

- 线下直播间照片。
- 公司办公环境照片。
- 宿舍或周边生活环境照片，如果真实可展示。
- 运营带教或团队工作场景照片。

聊天素材发送原则：

- 没探测到强意愿前少发素材，避免像群发广告。
- 候选人问内容、问收入、问案例时，再发一个最匹配的主播账号或内容案例。
- 素材要能证明“直播内容是什么”“运营怎么带”“环境是否真实”，不要只发炫耀型截图。

## 不建议写进岗位详情

```text
轻松月入10万
保证赚钱
不用努力
无门槛高薪
稳赚
不播也有底薪
颜值越高收入越高
私下维护粉丝
无条件返钱
```

这些表达可能短期提高点击，但会带来误解、低质量咨询和后续纠纷。

## 待用户确认口径

- 全职保底 6K 是否为当前默认起步口径。
- 6-10K 是否适合作为 BOSS 薪资字段。
- 保底补差是按总流水、主播分成后收入，还是另有公司内部口径。
- 全职有效时长是否固定写 156 小时。
- 住宿押金、主动退出扣除项是否要在岗位详情公开写，还是只在面聊时说明。
- 抖音线上协议/入会约的准确名称和退出规则。
- 奖励是否适合写进岗位详情，还是作为聊天补充。

## 建议验证方式

- 观察窗口：3-5 天。
- 主要指标：
  - 岗位曝光。
  - 详情打开率。
  - 打招呼到聊天打开率。
  - 微信采集率。
  - 电话/面聊推进数。
- 对照方式：
  - 第一轮不要同时改标题、薪资、城市和详情。
  - 如果回复多但无效咨询多，优先收紧第一屏：“线下全职”“按排班直播”“保底不是底薪”。
  - 如果曝光低，优先测标题关键词：`0基础`、`保底6K`、`包住`、`一对一带教`。
