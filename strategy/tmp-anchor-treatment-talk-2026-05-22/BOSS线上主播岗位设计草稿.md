## 推荐岗位定位

岗位方向：线上居家抖音互动娱乐主播。

核心人群：

- 想居家做直播，不方便到线下直播间的人。
- 有时间稳定开播，但没有直播经验的人。
- 想做抖音、想练表达、想做个人账号，但不知道从哪里开始的人。
- 做过带货或娱乐直播，想换成更重内容互动、不靠暧昧维护的人。
- 在二三线城市、县城、学校周边或家里，有开播环境和稳定时间的人。

不主打人群：

- 只想随便播几天试试，不愿意按计划学习和复盘的人。
- 没有稳定开播时间、设备和网络环境的人。
- 只想靠高保底，不关心直播内容的人。
- 只想私下维护粉丝、擦边聊天或违规内容的人。

## BOSS 发布字段建议

### 岗位标题

主推标题：

```text
居家抖音主播｜0基础可教｜线上
```

标题设计原因：

- `居家`：第一眼区分线上岗位，吸引不方便到场的人。
- `抖音主播`：明确平台和岗位类型。
- `0基础可教`：降低小白顾虑。
- `线上`：避免候选人误以为要到杭州或线下直播间。

备用标题：

```text
线上互动主播｜0经验｜运营带教
居家娱乐主播｜不带货｜可培训
抖音素人主播｜线上孵化｜高分成
```

标题测试建议：

- 第一轮主推 `居家 + 抖音主播 + 0基础`。
- 如果咨询多但候选人只想极低投入兼职，可测试把 `稳定开播` 放入详情第一屏。
- 如果曝光低，可测试 `线上互动主播`、`居家娱乐主播`、`抖音素人主播` 三组关键词。

### 岗位类别

建议优先选择：

```text
主播 / 网络主播 / 视频主播
```

不要放到客服、销售或泛兼职类目，避免推荐人群过散。

### 薪资字段

建议先用：

```text
5-10K
```

原因：

- 线上岗位没有住宿优势，第一屏更需要突出“居家 + 可教 + 成长空间”。
- 线上保底和兼职保底口径需要确认后再写得更满。
- 如果确认线上全职保底 6K 也适用，可测试 `6-10K`。

详情页必须补充：

- 收入由直播时长、内容表现、账号成长、分成和保底选择共同影响。
- 拿保底和不拿保底分成不同，正式开播前确认。
- 保底不是无条件底薪，需要按排班/时长/运营规则开播后计算。

### 工作地点

建议：

```text
线上居家 / 远程
```

详情页写清：

- 不需要到杭州线下直播间。
- 需要有安静开播环境、稳定网络和基础设备。
- 具体设备要求由运营面聊确认。

### 经验与学历

建议：

```text
经验不限 / 学历不限
```

要求写法：

- 0 经验可以教。
- 不要求才艺基础。
- 需要愿意出镜或按账号方向开播。
- 需要能稳定排时间直播和复盘。
- 需符合抖音直播平台实名认证和开播要求。

### 关键词

建议关键词：

```text
线上主播、居家主播、抖音主播、娱乐主播、互动主播、零基础、小白、素人孵化、线上培训、一对一带教、运营带教、高分成、起号、涨粉、远程
```

不建议关键词：

```text
轻松月入10万、无门槛暴富、躺赚、日结保底、不用露脸、无需学习、无条件高薪
```

## 岗位详情页文案

### 第一屏开头

```text
我们招线上居家抖音互动娱乐主播，0经验可以教，不需要到线下直播间。前期运营会带你熟悉直播内容、互动节奏和账号复盘；收入按直播表现、时长、分成和保底规则计算，保底不是无条件底薪。
```

第一屏要解决三件事：

- 明确这是线上居家岗位。
- 让小白知道不是“会了才能来”，而是可以带教。
- 先把保底和底薪区分清楚，避免误解。

### 我们做什么直播

```text
我们做的是抖音互动娱乐直播，不是传统带货，也不靠私下暧昧维护。重点是直播间互动、表达感、节目效果和稳定开播。

线上主播不用到公司直播间，但需要配合运营做直播内容、开播节奏、复盘调整和账号成长。
```

### 你能获得什么

```text
1. 线上带教：运营带你熟悉直播内容、互动话术、起号节奏和复盘方式。
2. 分成选择：拿保底分成 40%，不拿保底分成 45%，正式开播前确认。
3. 保底选择：符合时长和排班规则时可按保底规则计算，具体金额面聊确认。
4. 内容方向：抖音互动娱乐直播，不是传统带货，不要求你一开始就会卖货。
5. 成长空间：适合想练表达、做账号、积累精准直播粉的人。
6. 奖励：新人赛、成熟主播增幅赛、转介绍等奖励按公司当期规则执行。
```

### 工作内容

```text
1. 按约定时间在线开播。
2. 配合运营完成直播内容、互动节奏和复盘调整。
3. 学习表达、互动、控场、粉丝关系维护。
4. 根据账号情况参与短视频或直播素材优化。
5. 遵守抖音平台规则，不做违规内容。
```

### 任职要求

```text
1. 经验不限，小白可教。
2. 有稳定网络和适合开播的环境。
3. 能按约定时间直播，愿意复盘和练习。
4. 对抖音、直播、互动内容有兴趣。
5. 符合抖音直播平台实名认证和开播要求。
```

### 我们不希望你误解

```text
1. 线上岗位不等于随便播，稳定开播和复盘很重要。
2. 保底不是无条件底薪，需要符合直播时长、排班和运营规则。
3. 我们不收培训费、报名费、签约费。
4. 签的是抖音平台线上合作/入会相关协议，不签线下绑定合同；具体退出规则面聊时讲清楚。
5. 主播收入和直播时长、内容表现、学习配合度、账号成长、平台流量有关，不承诺无条件高薪。
```

### 适合你，如果你是

```text
1. 想居家做抖音直播，但不知道从哪里开始。
2. 没直播经验，但愿意学表达、互动和复盘。
3. 有固定空闲时间，希望线上长期做一件事。
4. 做过直播但不想再靠暧昧维护或传统带货。
5. 想做自己的账号，愿意按运营建议一点点调整。
```

### 不太适合你，如果你是

```text
1. 没有稳定开播时间。
2. 没有基本网络、设备或安静环境。
3. 只想挂名拿保底，不想开播和复盘。
4. 不愿意学习直播话术和内容节奏。
5. 期待不努力就稳定高收入。
```

## BOSS 第一条招呼语

### 通用小白版

```text
你好，我这边招线上居家抖音互动主播，0经验可以教，运营会带内容和复盘。看你经历还挺适合先了解一下直播方向，要不要我发你看看我们具体做什么内容？
```

设计点：

- 先讲线上、居家、0经验、运营带教。
- 不在第一句堆太多保底和分成，避免像广告。
- 结尾用“看内容”推进微信或电话。

### 学生/空闲时间版

```text
你好，我们这边有线上抖音互动主播，0经验可教，主要看你有没有稳定时间和学习意愿。你如果想了解直播到底做什么内容，我可以先发你看看。
```

### 有直播经验版

```text
你好，看你有直播相关经历。我们这边做线上抖音互动娱乐直播，不是传统带货，也不靠私下暧昧维护，运营会带起号和复盘。你要不要看看我们现在的直播内容和分成方式？
```

### 看过岗位未投递版

```text
刚看到你看过我们线上主播岗位。我简单说一下：居家线上、0经验可带、抖音互动娱乐方向。你主要想了解收入、直播内容，还是时间要求？
```

## 聊天承接结构

### 候选人问“你们做什么内容”

```text
我们是抖音互动娱乐直播，不是传统带货，也不做私下暧昧维护。
我可以发你看看直播内容，不过 BOSS 这边不太方便发视频，微信上看会更直观。你方便加一下吗？
```

### 候选人问“线上怎么带”

```text
线上主要通过运营沟通、直播复盘和内容调整来带。前期会先看你的表达状态、账号情况和可开播时间，再安排适合你的内容方向，不是让你自己乱播。
```

### 候选人问“保底是不是底薪”

```text
不是底薪，这点先讲清楚。保底是你按约定时长和运营规则直播后，如果收入没达到约定保底，公司按规则补差；不是不开播也有的固定工资。
```

### 候选人问“没经验能不能做”

```text
可以，线上岗位也可以从 0 开始。我们更看重你有没有稳定时间、愿不愿意学、能不能按建议复盘。直播能力是练出来的，不是天生就会。
```

### 候选人问“用不用自己的号”

```text
这个要看你的账号情况。运营会看你之前的短视频风格、是否违规、你是否担心朋友刷到，再判断用老号还是新号。新号不是一定没流量，核心还是直播内容和精准人群。
```

### 候选人问“设备要求”

```text
基础要求是网络稳定、画面和声音清楚、环境别太吵。具体设备不用你现在一次性准备，我先了解你的情况，再让运营判断怎么开始成本最低。
```

### 候选人问“签约会不会被绑定”

```text
我们不收签约费、培训费，也不签线下绑定合同。走的是抖音平台线上合作/入会相关协议，具体周期、退出规则和注意事项会在面聊前讲清楚，你确认能接受再继续。
```

### 候选人拒绝电话

```text
没事，那我们先文字沟通。你现在最关心的是收入、直播内容、时间要求，还是用不用自己的号？
```

## 候选人筛选问题

不要一次全问，按聊天进度拆开：

1. 你现在每天大概哪个时间段方便稳定开播？
2. 之前有做过直播、短视频、销售、客服或线上娱乐类内容吗？
3. 你更关心收入稳定、线上自由，还是账号成长？
4. 你现在有适合开播的网络和环境吗？
5. 你对线上直播最大的顾虑是什么？

破冰可找：

- 同城市或同省份。
- 是否学生、宝妈、刚毕业、在家待业或有固定空闲时间。
- 是否做过短视频、直播、销售、客服、社群。
- 是否喜欢抖音、游戏、互动、表达类内容。

破冰时避免直接问：

- 男女朋友。
- 家庭情况。
- 当前收入。
- 过多隐私经历。

## 图片与素材策略

BOSS 岗位建议上传：

- 线上直播内容截图或合规直播间画面。
- 运营复盘/培训流程示意图。
- 主播成长路径或新人训练流程。
- 公司办公环境或团队照片，用来证明公司真实存在。

聊天素材发送原则：

- 没探测到强意愿前少发素材。
- 候选人问“做什么内容”“收入怎么来”“线上怎么带”时，再发一个最匹配的案例。
- 发案例时优先发“能看懂直播内容”的账号或片段，不只发高收入截图。

## 不建议写进岗位详情

```text
轻松月入10万
线上躺赚
不用播也有保底
无门槛暴富
不需要学习
不用露脸也高薪
保证赚钱
无条件返钱
随便播就能火
```

这些表达会提高误解和无效咨询，也容易让候选人把线上岗位理解成低投入高回报。

## 待用户确认口径

- 线上岗位是否默认有保底，还是只对全职/达标时长开放保底。
- 线上全职保底是否同样 6K 起。
- 线上兼职是否要单独开岗位，而不是混在本岗位里。
- 线上岗位的最低开播时长、有效天和复盘要求。
- 线上主播设备是否由公司提供、补贴，还是主播自备。
- 抖音线上协议/入会约的准确名称和退出规则。
- 是否允许直接写“不带货”“不靠暧昧维护”，还是改成更温和表达。

## 建议验证方式

- 观察窗口：3-5 天。
- 主要指标：
  - 岗位曝光。
  - 详情打开率。
  - 打招呼到聊天打开率。
  - 微信采集率。
  - 电话/线上面聊推进数。
- 对照方式：
  - 第一轮只测 `居家抖音主播｜0基础可教｜线上`。
  - 如果咨询很多但执行意愿低，第一屏增加“需要稳定开播和复盘”。
  - 如果曝光低，测试标题关键词：`线上互动主播`、`居家娱乐主播`、`抖音素人主播`。
  - 如果微信率低，优化首句 CTA：先让对方看直播内容，再解释保底和分成。
