# 候选人曝光策略

## 1. 方向定位

候选人曝光是当前最重要的策略方向。

这里的“曝光”不是只看我们看到了多少候选人，而是反过来研究：BOSS 怎么样才会把我们的职位、账号和招聘动作推给更多合适候选人，让更多候选人进入可触达范围。

岗位吸引力和岗位包装归在本方向下面维护。原因是候选人点击、停留、回复和后续转化在平台看来都可能反过来影响曝光，岗位本身是否有吸引力是曝光系统的上游信号之一。

核心问题：

- 什么操作会让 BOSS 更愿意给我们推荐候选人？
- 什么职位信息、岗位包装、账号行为、筛选动作或打招呼节奏，会影响推荐流量？
- 哪些动作只是忙碌，不能带来更多有效候选人？

## 2. 当前原则

- 先追求有效曝光，不追求无意义的候选人数量。
- 曝光策略必须能落到可观察事实，例如列表曝光、卡片曝光、详情打开、打招呼点击、聊天打开。
- 不把“候选人质量好坏”写成插件端结论，只在策略复盘中作为人工或分析系统判断。
- 没有日志或人工样本支撑的推断，都标为“待验证”。

## 3. 重点观察方向

### 3.1 岗位吸引力与岗位包装

待沉淀内容：

- 职位标题、薪资表达、工作地点、福利亮点、岗位要求写法是否影响点击和回复。
- 岗位描述是否把核心吸引点放在候选人第一眼能看到的位置。
- 同一岗位不同包装方式，对候选人曝光、详情打开、打招呼回复的影响。
- 哪些包装会带来无效候选人，哪些包装能带来更匹配候选人。

### 3.2 职位与账号是否被更多候选人看见

待沉淀内容：

- 职位标题、薪资、城市、工作地点、岗位描述是否影响候选人进入推荐池。
- 账号活跃度、连续操作、回复及时性是否影响系统分发。
- 不同时间段操作是否影响曝光量。

### 3.3 筛选动作是否影响推荐质量和数量

待沉淀内容：

- 筛选条件过宽时，是否带来大量无效候选人。
- 筛选条件过窄时，是否导致候选人池变少。
- 哪些筛选条件组合更容易带来可打招呼候选人。

### 3.4 详情打开和打招呼是否反向影响推荐

待沉淀内容：

- 高频打开详情是否让系统更理解招聘偏好。
- 对某类候选人持续打招呼后，推荐是否向同类候选人靠拢。
- 快速跳过、频繁无效点击是否会降低后续推荐质量。

### 3.5 低效曝光反例

待沉淀内容：

- 看起来候选人很多，但打开率、打招呼率、回复率都差的操作。
- 只增加操作量，不增加有效候选人的动作。
- 容易让账号进入低质量批量操作状态的行为。

## 4. 可关联事实事件

- `candidate_filter.panel_opened`
- `candidate_filter.applied`
- `candidate_list.list_viewed`
- `candidate_list.card_exposed`
- `candidate_detail.opened`
- `candidate_greeting.clicked`
- `candidate_greeting.succeeded`
- `candidate_chat.opened`

这些事件只能证明发生了什么。策略有效性需要后续按岗位、时间段、候选人类型和转化结果做复盘。
