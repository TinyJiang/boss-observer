# 主动打招呼策略

## 1. 方向定位

主动打招呼是独立于曝光和聊天转化的第三个大方向。

曝光解决的是“能不能看到更多合适候选人”；主动打招呼解决的是“看到以后，候选人愿不愿意回复”。它同时考验岗位本身有没有吸引力，以及第一句招呼语是否能让候选人愿意进入聊天。

核心问题：

- 什么样的候选人值得优先主动打招呼？
- 什么岗位包装更容易让候选人回复招呼？
- 招呼语应该突出岗位、薪资、地点、发展机会，还是先降低打扰感？
- 什么发送节奏和候选人选择方式会提高回复率，而不是只增加点击量？

## 2. 当前原则

- 主动打招呼不只看发送数量，核心看回复率和后续聊天推进。
- 岗位吸引力是招呼回复率的一部分，但岗位包装的长期沉淀放在 `candidate-exposure.md`。
- 招呼语策略只记录脱敏结构，不保存候选人完整聊天原文。
- 不把单次高回复经验直接写成通用结论，先按岗位、城市、候选人类型验证。

## 3. 重点观察方向

### 3.1 候选人选择

待沉淀内容：

- 哪类候选人适合直接打招呼，哪类需要先看详情。
- 活跃状态、求职意向、薪资、地点、经验、学历等字段怎样影响回复率。
- 哪些候选人看起来匹配，但实际回复率或后续推进很差。

### 3.2 岗位卖点与招呼语匹配

待沉淀内容：

- 招呼语里优先放薪资、距离、工作内容、发展空间还是稳定性。
- 不同岗位应该突出不同卖点，避免一套话术到处用。
- 候选人卡片信息能否决定第一句话的重点。

### 3.3 招呼语结构

待沉淀内容：

- 开头是否直接说明岗位，还是先表达匹配理由。
- 一句话招呼、两句话招呼、带问题招呼的回复差异。
- 哪些表达容易显得群发，降低回复。

### 3.4 发送节奏

待沉淀内容：

- 不同时间段发送的回复率差异。
- 连续大量打招呼是否影响账号后续曝光或回复质量。
- 每轮筛选后先打哪些候选人，后打哪些候选人。

### 3.5 低回复反例

待沉淀内容：

- 发送量高但回复率低的话术。
- 候选人匹配度看似高但不愿回复的岗位表达。
- 容易被候选人认为是模板群发的表达。

## 4. 可关联事实事件

- `candidate_list.card_exposed`
- `candidate_detail.opened`
- `candidate_greeting.clicked`
- `candidate_greeting.succeeded`
- `candidate_greeting.failed`
- `candidate_chat.opened`
- `candidate_chat.snapshot_captured`

这些事件只能证明曝光、查看、打招呼和聊天打开等事实。招呼语是否有效，需要结合候选人回复、后续聊天推进和人工复盘判断。
