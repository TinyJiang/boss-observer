# 聊天话术转化策略

## 1. 方向定位

聊天话术转化是当前第二重要的策略方向。

候选人被曝光、打开详情、打招呼之后，真正能不能推进，主要看聊天里有没有把候选人带到下一步。这里沉淀的是话术、节奏、异议处理和跟进方式。

核心问题：

- 候选人回复后，什么开场更容易继续聊下去？
- 如何更快确认候选人的求职意向、薪资、地点、到岗时间和顾虑？
- 什么时机适合约面、换微信或推进下一步？
- 哪些话术会造成候选人沉默、反感或流失？

## 2. 当前原则

- 聊天策略只沉淀方法，不在插件端评价聊天质量。
- 不保存完整敏感聊天原文，策略文档只写脱敏摘要和可复用结构。
- 转化不是只看回复数量，要看候选人是否推进到下一步。
- 不同岗位、城市、薪资段的话术需要分开验证。

## 3. 重点观察方向

### 3.1 开场与承接

待沉淀内容：

- 候选人刚回复时，如何承接对方兴趣。
- 主动打招呼后，第一句话如何降低对方防备。
- 不同候选人状态下，直接介绍岗位和先问需求的差异。

### 3.2 需求确认

待沉淀内容：

- 如何确认求职意向、期望薪资、通勤范围、到岗时间。
- 如何避免一次问太多导致候选人不回。
- 什么信息必须先问，什么信息可以后置。

### 3.3 异议处理

待沉淀内容：

- 候选人对薪资、地点、时间、岗位内容、公司稳定性的常见顾虑。
- 哪些回答能继续推进，哪些回答容易让聊天结束。
- 对不匹配候选人如何礼貌结束，避免浪费后续精力。

### 3.4 约面与换微信

待沉淀内容：

- 什么信号出现后适合约面。
- 什么信号出现后适合换微信。
- 换微信前需要确认哪些信息，避免换完后断联。

### 3.5 跟进节奏

待沉淀内容：

- 候选人未回复时，多久跟进一次合适。
- 候选人只回复一句时，如何补充信息继续推进。
- 已换微信后的跟进节奏和复盘方式。

## 4. 可关联事实事件

- `candidate_greeting.clicked`
- `candidate_greeting.succeeded`
- `candidate_chat.opened`
- `candidate_chat.snapshot_captured`
- `candidate_chat.wechat_captured`
- `candidate_chat.capture_failed`

这些事件只能证明聊天窗口打开、快照采集和微信信息可见等事实。话术是否有效，需要结合脱敏样本、人工复盘和后续转化结果判断。
